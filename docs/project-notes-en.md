# Project notes: Atari 2600 AV-mod RCA bracket (Autodesk Fusion + 3D printing)

Working notes for a small 3D-printed bracket that holds the jacks of an Atari 2600 AV mod. I'm new to Fusion, digital calipers and Git, so these notes include the menu paths and steps I had to figure out along the way.

**Setup:** Mac, Creality Ender 5 S1 (0.4 mm nozzle, 220×220×280 mm build volume, textured PEI bed), PLA, sliced in Creality Print.

The Python script in `english/av_bracket_en.py` (with `av_bracket_en.manifest`) is the source of truth for the geometry.

## Goal

Reproduce a small 3D-printed bracket that clips under the back of an **Atari 2600** and holds the jacks of an **AV mod**. The original I'm copying holds 1 S-Video and 3 RCA jacks. **My version replaces the S-Video cutout with a 4th RCA hole, so it has 4 identical RCA holes.** The flat ribbon cable from the mod runs into the bracket, and the "L" tab on top acts as a clip/hook.

## How the part is built

The part is generated by a **Fusion Python script** (not modeled by hand). It runs from *Utilities > Add-Ins > Scripts and Add-Ins* (Shift+S), opens a new design and builds parametric timeline features in this order:

1. **Body:** a trapezoid sketched on the XY plane (length × height) and extruded along Z (depth). The front face is 81 mm at the top and 71 mm at the bottom, because both ends are slanted 5 mm.
2. **Shell:** 2 mm walls. The removed face is the **back** (opposite the holes), so the box is open at the back.
3. **Slanted back:** a wedge cut on the YZ plane so the depth goes from 24.94 mm at the bottom to 22.00 mm at the top (~8.1°). This matches the slanted rear of the Atari case. The narrow side is at the top, against the Atari.
4. **Optional square cutout:** the old S-Video opening, now off (`USE_CUTOUT = False`).
5. **4 RCA holes:** cut through the front wall only.
6. **"L" tab:** on the top face, set back from the hole face. The vertical post is on the left and the plate overhangs to the right.

## Important context and lessons learned

- **The RCA jacks only press-fit into the holes.** Hole size is the most critical fit. A small test plate with holes at 8.2 / 8.4 / 8.6 mm is a good idea before reprinting the whole part.
- **Early estimates were about 2× too big** (150 mm long) because I worked from screenshots without scale. All main dimensions are now real caliper measurements. Only the tab and hole positions are photo estimates.
- **Caliper units:** once the display was accidentally in inches ("in" shown on the display). My caliper's **mm/in/F** button changes units. Always check that "mm" is shown, and zero the caliper with the jaws closed.
- **The first print didn't fit perfectly** because the Atari's back is slanted. That was fixed with the slanted-back cut (TOP_DEPTH). If it's still slightly off, adjust TOP_DEPTH in 0.5 mm steps.
- **Script assumptions** I haven't confirmed: both ends slant equally, and the narrow (22 mm) side is at the top, against the Atari.

## Printing setup

- Orientation: **RCA-hole face down on the bed**, open back facing up. The holes come out round with no support.
- Enable **supports only under the L tab**, because it's set back from the edge and its underside overhangs.
- PLA starting point: 0.2 mm layers, 200–210 °C nozzle, 60 °C bed, 3 walls, 15–20% infill. A brim helps the small tab area.

## Fusion how-tos we already solved

- **Run a script:** Shift+S → select the script → Run.
- **Add a script from a folder** (for example a Git repo): Shift+S → **+** → add an existing script from the computer. The folder name, `.py` and `.manifest` must all have the same name. Scripts live in `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/Scripts/` (Finder: Cmd+Shift+G).
- **Export STL:** right-click the body **Bracket** in the Browser → **Save As Mesh** → STL (Binary), Millimeter, Refinement High. In *Utilities > Make > 3D Print*, the OK button stays greyed out unless **Preparation Type = Save to Local File**.
- **Rename or delete a script:** create a new script with the desired name and paste the code in, or rename or delete the folder in the Scripts directory.
